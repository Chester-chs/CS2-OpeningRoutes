# CS2 OpeningRoutes

[English](README.md) | **简体中文**

**从职业比赛学习 CS2 开局：T/CT 控图与道具反制、手枪局打法、职业选手示范。**

OpeningRoutes 是一个开发中的 CS2 学习工具，面向希望系统学习职业打法的玩家。项目从职业赛事 Demo 提取路线和道具，结合原比赛示范与经验证的教学，逐步整理成可检索的学习案例，提供 Windows 软件和功能网页版。

> **项目状态：v0.1.0 本地开发预览。** 已实现真实 Demo 提取、道具检索、完整回合路线、独立手枪局、教学整理与审核导出。完整教学需要补齐原片、图示和游戏内复现，不会把提取记录标成已验证教程。尚无公开发行下载或公网在线体验。

参阅[使用说明](docs/usage.zh-CN.md)，了解运行、导入、教学整理和网页内容包。下述功能描述包含已实现的基础流程与仍需完善的内容目标。

## 核心功能与内容目标

### T/CT 开局控图与道具反制

按地图和区域，学习双方如何争夺、维持或重新取得控制权：

- T 方第一时间抢占区域所需的道具、行动路线与进入配合。
- CT 方开局防守、延缓推进、阻止抢占及反清方案。
- 面对对方烟、闪、火、雷时的应对案例。
- 每套方案的出生位置、装备、人数、投掷顺序、时机与后续站位。

### 职业选手与战队的手枪局打法

独立浏览 T、CT 两侧的职业手枪局，比较不同选手和战队在多场比赛中的选择：

- 装备分配、开局站位、个人路线和全队展开。
- 道具配合、进攻或防守节奏、首杀与首个阵亡。
- 下包、后续转移和回合结果。
- 成功与失败案例，以及相应的比赛原片和样本统计。

### 完整道具库与不同投法

整理导入职业比赛中的烟、闪、燃烧弹/燃烧瓶、HE 等道具，按地图、区域、阵营、用途、选手和战队查找。

同一用途下可比较不同站位、瞄点、出手方式与时机，并查看采用这些投法的职业选手案例。单颗道具可关联单人连续投掷或多人配合方案，便于从一个投法扩展学习整套行动。

### 职业示范与跟练教学

观看职业选手在真实比赛中的准备、投掷、配合与后续行动，同时查看清晰的站位图、瞄点图、动作步骤和教学复现。

原比赛片段与教学复现分别标记，保留比赛来源、回合、地图版本和验证状态。支持收藏案例、记录观察与练习目标。

## 学习方式

- **按区域：** 地图 → 区域 → T/CT → 控图或反制方案 → 道具与职业示范。
- **按手枪局：** 地图 → 选手或战队 → T/CT → 装备、路线与配合 → 回合对比。
- **按道具：** 地图 → 道具类型或用途 → 不同投法 → 职业案例与教学。

桌面软件与功能网页版计划提供一致的核心学习入口，支持查找道具、研究手枪局和观看职业示范。

## 数据与内容

分析数据来自可核验的职业赛事 Demo。支持多名选手、多回合、跨比赛比较和完整回合时间轴，保留 CT 防守展开、T 默认及后续行动的背景。

道具库将随导入比赛和内容整理持续扩充，并标明覆盖地图、比赛时期和验证状态。统计保留胜负两类样本，显示使用次数、样本量和来源；教学复现单独管理。案例用于学习与比较，具体用法需要结合出生位置、装备和队友配合判断。
