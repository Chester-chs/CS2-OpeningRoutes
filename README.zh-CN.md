# CS2 OpeningRoutes

[English](README.md) | **简体中文**

只用职业赛事 Demo，学习 **职业选手与战队的 CT 开局防守方式、T 默认整体路线，以及个人和战队的手枪局风格**。

> **项目状态：想法已保存，暂缓开发。** 当前仓库只有介绍和规划，没有应用程序、安装包或可运行演示。先完善 [POVForge](https://github.com/Chester-chs/CS2-povforge)，以后明确提出继续时，再启动本项目。

## 解决什么问题

连续观看职业比赛后，很难系统比较：不同选手如何展开 CT 防守，T 方全队如何分散控图与转移，以及某名选手或战队在多场比赛里有哪些手枪局习惯。

OpeningRoutes 计划把职业赛事中的路线、时间、比赛背景和统计连接起来；从选手或战队的倾向出发，能回到具体回合核对，再形成自己的学习笔记。

**预期流程：**

导入职业赛事 Demo 并记录比赛来源 → 按地图、战队、选手与回合筛选 → 研究路线或手枪局倾向 → 回看支持结论的回合 → 保存学习案例。

## 核心特点

- **数据只来自职业赛事：** 使用职业战队参加赛事、联赛等比赛的 Demo；职业选手打的天梯 Demo 也不属于目标数据。
- **CT 开局防守：** 同时研究选手个人路线和全队防守展开，比较站位、到点时间与后续移动。
- **T 默认整体路线：** 提供全队、完整回合的路线与时间数据，支持选择默认阶段观察分工、分散控图和转移，不固定截取前 30 秒。
- **多选手、多回合、多场比赛：** 覆盖导入比赛中可用的全部参赛选手和正式回合；支持跨职业比赛整理与对比。分组显示不等于限制可分析的数据量。
- **职业选手与战队的手枪局风格：** 汇总多场比赛、T/CT 两侧手枪局中的装备、开局站位、路线、行动节奏、道具、首杀/首个阵亡、下包和结果等可核对信息。
- **结论有来源：** 统计显示样本量、时间范围和对应回合，成功与失败的手枪局都保留。
- **保留必要背景：** 记录赛事、日期、战队、阵容、地图版本、出生位置和装备等信息。
- **形成自己的学习案例：** 分别记录事实、自己的战术理解，以及下次练习想尝试的内容。
- **面向个人本地分析与学习：** 从战队倾向找到回合，也能从一个回合扩展研究同类案例。

## 已确认范围与分阶段开发

产品不设“只支持一名选手、两三个回合、前 30 秒”的限制。完整回合坐标是研究 T 默认的基础；CT 开局与 T 默认也支持普通正式回合，手枪局是并列的专题筛选。

以后通过分阶段交付控制开发难度：先做好职业赛事来源与全员、全回合数据，再做路线显示和比较，随后完成手枪局统计。先支持哪些地图、具体界面和性能指标待恢复开发时确定。验证时可以使用少量样本，但不能把验证样本写成产品限制。

Demo 中的位置与事件用于呈现发生了什么。默认阶段、角色与战术解释需要人工确认；数据缺失明确标注。风格描述要显示样本依据，不能由少数回合断言固定风格或最佳决策。

## 技术与验证

暂定 Python、现成的 [demoparser2](https://github.com/LaihoE/demoparser) 和绘图库。最终界面与存储方式以后确定。开始开发前，需要用真实职业赛事 Demo 核对解析兼容性、比赛来源、地图坐标、相对时间和正式手枪局识别。

以后可以使用 POVForge 导出的 POV 视频辅助理解；目前没有设计或实现联动接口。

详细范围、验收方式和恢复开发前的检查项见 [项目规划](docs/project-plan.zh-CN.md)。现有产品已有类似基础能力，本项目面向可回溯的个人分析与学习；尚未验证独特性或学习效果。
