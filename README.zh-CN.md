# CS2 OpeningRoutes

[English](README.md) | **简体中文**

**跟着职业选手或战队，学习 CS2 一块区域怎么打。**

OpeningRoutes 从职业比赛 Demo 提取全员路线、装备和事件，把学习内容组织成 **选手/战队 → 地图 → T/CT → 区域或角色位**。比较一个人在不同比赛和情境下的开局选择，打开对应的完整回合，再保存为自己的跟练清单。

> **v0.2.0 本地开发预览。** Windows 软件与功能网页版共用学习界面。选手区域档案、独立手枪局、全员回放、跟练记录、方案草稿和来源核验后的静态导出已经实现。比赛观察与经游戏内复现验证的教学分别标记。

从“**跟着选手学 → 选手 → Mirage → CT → A 区**”开始，查看常驻区域、前 30 秒移动和道具时序；切换“仅手枪局”，比较装备受限时的选择。[使用说明](docs/usage.zh-CN.md)

## 跟着人和位置学习

- **站位与移动：** 前 30 秒最常停留的区域、移动序列，以及对应的完整回合。
- **道具与时机：** 在路线背景中看谁先投、何时投、投完去哪。已有完整教学可继续打开职业原片、瞄点资料和复现示范。
- **情境变化：** 按手枪局、经济和比分筛选；每个切片显示唯一回合数、比赛数与不确定性。
- **对抗证据：** 并列双方区域人数、首次伤害、首杀、对手同期道具与回合结果。反制关系和战术目的仍需人工核对。
- **身份与时期：** 用 SteamID 识别选手，保留曾用名，按战队时期和地图时期分开（同一地图时期内跨补丁合并，并列出补丁构成）。确认同角色后可建立汇总组，个人档案继续保留。

## 从案例到跟练

选择一个来源回合，可以打开十名选手的全回合路线，或保存包含实际移动、道具时间和核对步骤的跟练清单。勾选进度与笔记保存在当前浏览器，可导出和恢复。

桌面端还能从同一真实回合生成“控图与反制”方案草稿，保留选手、时间和来源。没有开局道具的回合仍可跟练路线。方案发布沿用已有教学门槛，不会把统计结果或草稿当成已验证教程。

## 手枪局与已有资料

**手枪局保持独立入口**，可按地图、阵营、选手、战队和时期查看冻结结束装备、路线、首杀、下包和结果，也能进入该选手的区域档案。

CT 防守研究继续提供阵型、站位、战队习惯和情境比较，并连接新的学习入口。[研究方法与边界](docs/ct-research.zh-CN.md)

已有道具库、职业示范与复现教学作为回合学习的辅助资料保留。当前开发重点是“人 × 位置”的学习流程，不继续扩展道具归组或投法视频生产。

## 数据边界

档案只统计来源已核验、完整且无待复核异常的正式回合。4 Hz 路线采样与精确道具事件分别保存；前 30 秒用于归纳开局，完整回合不会截断。

“持续占位”表示一侧存活选手连续至少 2 秒出现在指定区域内，不能直接代表视野、火力覆盖或真正的控制权。首次伤害也只是接触的代理。落点区域的推测会标注距离。

少于 30 回合或 5 场比赛的档案标为探索性；至少 5 场才给出按比赛重采样的比例区间。频率和胜负用于描述样本，不代表最优打法或因果关系。旧版本、缺失资料、角色差异和小样本都会限制结论。
