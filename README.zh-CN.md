# CS2 OpeningRoutes

[English](README.md) | **简体中文**

用职业比赛 Demo 学习选手的开局路线：研究 **CT 开局如何展开防守**，以及 **T 默认前期如何分散、站位与控图**。

> **项目状态：想法已保存，暂缓开发。** 当前仓库只有介绍和规划，没有应用程序、安装包或可运行演示。先完善 [POVForge](https://github.com/Chester-chs/CS2-povforge)，以后明确提出继续时，再启动本项目。

## 解决什么问题

连续看几个职业回合后，很难记住同一名选手每局去了哪里、何时到达、在哪里停留，以及这些开局有什么不同。

OpeningRoutes 计划把人工挑选的几个回合放在一起，用雷达路线和统一的相对时间进行比较，并保存自己的学习笔记。

**预期流程：**

导入本地 Demo → 选择职业选手和回合 → 对比开局路线与时间 → 记录观察与理解 → 保存学习案例。

## 核心特点

- **围绕具体位置学打法：** 支持研究 CT 开局防守和 T 默认前期；每次比较同一阵营的回合。
- **多个回合放在一起看：** 最多三局，用不同颜色显示路线，方便比较前压、停留与移动等可观察差异。
- **路线带有时间信息：** 以冻结时间结束为起点，查看选定时间经过的位置。
- **保留必要背景：** 在数据可用时显示出生位置、初始装备、比赛、选手与回合来源。
- **形成自己的学习案例：** 分别记录事实、自己的战术理解，以及下次练习想尝试的内容。
- **适合个人本地使用：** 第一版围绕少量 Demo 和人工选择的回合设计。

## 第一版控制范围

一张待选地图、一名选手、同一阵营的两到三个回合，以及冻结时间结束后的前 30 秒。采用静态雷达、路线叠加和简单时间控件。

T 默认可能持续更久；第一版只研究它的开局部分。完整回放、自动识别角色与战术、自动判断最佳决策、云账号和共享社区均留待以后评估。

Demo 中的位置与事件用于呈现发生了什么。选手为什么这样做、是否值得模仿，由用户结合 POV 和比赛背景写成分析；缺失信息明确标注。

## 技术与验证

暂定 Python、现成的 [demoparser2](https://github.com/LaihoE/demoparser) 和绘图库。最终界面与存储方式以后确定。开始开发前，需要先用真实 Demo 核对解析兼容性、地图坐标和相对时间。

以后可以使用 POVForge 导出的 POV 视频辅助理解；目前没有设计或实现联动接口。

详细范围、验收方式和恢复开发前的检查项见 [项目规划](docs/project-plan.zh-CN.md)。现有产品已有类似基础能力，本项目的定位是一个范围明确、方便自己使用和理解的小工具；尚未验证独特性或学习效果。
