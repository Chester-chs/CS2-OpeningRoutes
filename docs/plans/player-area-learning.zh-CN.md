# 选手/战队×区域学习

待确认，阈值待校准。

1. 跟着选手学：选手/战队→地图→T/CT→区域/角色，互链CT研究/手枪局/完整回合。

2. 量化：冻结结束=0秒，区域为审核点位集合。4Hz：N方=区内存活人数；己>0敌=0持续2秒为占位（滤穿行），双方>0为争夺，均0为无人，缺测未知。回合末2秒判占位，另列胜负；非真实控制。首伤作接触代理，伤/杀定位并列道具时序；落点推测标距，反制人工确认。前30秒驻留≥2秒或向区投掷即入样。

3. 模型：人×地图版本×阵营×区域/角色→站位分布、路线/道具序列、经济/比分/手枪局切片、回合ID、缺失率/区间。导入补事实，按图后台预计算缓存；键含源哈希、提取/审核修订、区域/身份/角色版本、算法/窗口/筛选。不改旧表。

4. T：路线缺逐点区域，T快照缺选手明细，补提取，缺则不统计。CT快照不变；T用0/5/10/15/20/25/30秒覆盖快/慢展开，补T后场，聚类/情境按阵营，另拟T名称。

5. SteamID识人，队伍/时期分开。同队同期同角色经确认汇总，保留成员。各切片列唯一回合/比赛数；<30回合或<5场仅探索，≥5场按比赛重抽样给习惯占比95%区间；补相关Demo。

6. 衔接：同回合生成方案草稿及站位→时机→道具→移动跟练单，沿用发布门槛；无道具只生跟练单。统计/静态包仅取来源已核验的有效完整回合及按需回放；catalog不变；包schema_version=1增可选索引。
