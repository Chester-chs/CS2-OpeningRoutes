# 使用 OpeningRoutes 本地预览

当前版本为 v0.1.0 开发预览，提供 Windows 软件与功能网页版。真实比赛的提取记录和经过复现核验的完整教学分别展示；提取成功不代表已经学会并验证一套投法。

## Windows 软件

解压 Windows 分发包，进入 `OpeningRoutes` 文件夹，双击 `OpeningRoutes.exe`。请保留同一目录下的 `_internal` 文件夹。

首次启动会载入分发包附带的比赛提取记录（如构建时选择了样本）。自己的资料保存在 `%LOCALAPPDATA%\OpeningRoutes`，更新软件不会覆盖该目录；备份时复制整个目录。程序使用本地 8765 端口，请先关闭其他占用该端口的 OpeningRoutes 实例。

收藏与练习笔记保存在本机的 WebView 浏览器资料中。可在“我的收藏”导出学习记录，也可在另一端导入备份。两端不自动同步。

## 从职业比赛 Demo 到教学

1. 在“数据与内容管理”选择 CS2 `.dem` 文件，填写赛事、对阵、比赛日期和 HTTPS 来源链接。当前单文件最大 2 GiB，不直接导入压缩包。
2. 点击“开始提取”。后台解析正式回合、投掷、道具飞行轨迹和十名选手的完整回合路线；长任务可取消，失败或中断后可重新选择原文件导入。相同文件通过 SHA-256 识别并复用已完成结果。
3. 核对比赛来源、阵容、地图和结果，填写核验记录。未经核验的比赛不会进入职业手枪局统计或正式网页发布包。
4. 在“道具库”选择一条记录。查看原始出手时间、坐标、视角、匹配的飞行轨迹和完整回合背景。路线采用全回合采样，界面明确显示采样频率；出手数据单独保留。
5. 进入“整理教学”，补充战术场景、装备/出生位条件、站位、瞄点、按键、移动/跳跃、时机、效果、配合、失败修正与反制。添加真实站位图、瞄点图和职业比赛原片；原片与教学复现视频分别关联。
6. 在游戏内核验投法，填写验证的游戏/地图版本、日期和核验人。Demo 的视角数值可辅助复现；它不能替代对实际按键、图示和操作步骤的验证。
7. 保存草稿，或通过完整性检查后发布完整教学。修改已验证的操作、图示或地图版本后，需要重新验证并确认，才能继续发布。
8. 在“控图与反制”把投掷组织为方案，记录角色、相对时间、后续行动及对应反制方案。未通过验证的步骤不能成为已验证发布方案。
9. 从“数据与内容管理”导出已审核内容包。导出包含目录、来源、相关完整回合路线、选中的媒体及文件校验清单，不包含原始 Demo、私人笔记或未发布教学草稿。

外部视频支持 HTTPS MP4/WebM、YouTube 视频及来源链接；本地可添加 MP4/WebM 和 PNG/JPEG/WebP，单媒体最大 250 MiB。外部来源是否可播放取决于该服务及视频当前状态。

## 手枪局

“手枪局”是独立入口。可以按地图、阵营、选手、战队、比赛和时期筛选，查看冻结结束装备、全队路线、首杀/首亡、下包及回合结果。

胜负案例同时保留。汇总按唯一回合计数，装备分布按选手的冻结结束快照计数。识别依据是 Demo 中的常规半场设置、非热身冻结结束及完成的回合，不按武器类型猜测，也不把加时首回合套成手枪局。异常重开会显示需要复核。

## 网页内容

正式网页版只读取审核发布包，提供检索、教学、视频、手枪局、回合路线与本浏览器的学习记录。网页不提供本机 Demo 导入或教学编辑。

内容包解压后，其 `manifest.json`、`catalog.json`、`timelines` 与 `media` 应放在网页的 `content` 子目录中。通过 HTTP/HTTPS 托管整个网页目录；不要直接双击 HTML。支持部署到站点子路径，目录与回合文件会校验 SHA-256。

本地网页预览可以包含尚未形成教程的真实提取记录，会明确标为“本地提取记录预览”。这类预览不代表已有完整教学或已公开上线。

## 从源码运行

需要 Python 3.12、uv、Node.js 22.12 或更新版本。已在 Windows / Python 3.12 / Node.js 24 上验证。

```powershell
uv sync --extra dev
cd web
npm ci
npm run build
cd ..
uv run python launch.py
```

本地浏览器模式：

```powershell
uv run python launch.py --browser --port 8765
```

然后打开 `http://127.0.0.1:8765`。源码运行默认使用 `.local/data`；可通过 `--data` 指定自己的数据目录。

构建 Windows 软件：

```powershell
uv run python scripts/build_desktop.py
```

从本地资料生成正式网页构建目录：

```powershell
uv run python scripts/build_web.py --data .local/data
```

仅供自己检查真实提取记录的网页预览：

```powershell
uv run python scripts/build_web.py --data .local/data --local-preview
uv run python -m http.server 8766 --bind 127.0.0.1 --directory artifacts/web-preview
```

## 当前边界

- 已核验的解析样本来自同一职业系列赛的 Ancient 和 Mirage，尚不能据此宣称覆盖所有赛事、地图或比赛时期。
- 当前路线为世界坐标示意，保留高度值；尚未提供经校准的分层雷达底图。
- 按键教学、区域命名、投法归组、配合解释和反制结论需要人工核对。当前同区域同类型案例可供比较，不代表已自动判定为同一投法。
- 不自动录制或剪辑职业 POV，也不自动生成“已验证”教程。真实完整教程的数量以应用实际显示为准。
- Windows 运行需要系统 WebView2；软件包尚未进行代码签名或在其他电脑上验证。
- 当前没有公开托管的在线服务或自动账号同步。静态网站与媒体需要自行部署。
